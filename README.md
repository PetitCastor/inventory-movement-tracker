# Inventory Movement Tracker

Estimates where your **Star Citizen** items are by reading the game's `Game.log`. It gives each estimate a calibrated probability, and lists the log lines it rests on.

Work in progress toward version 1.0. It succeeds [Inventory Tracker](https://github.com/PetitCastor/inventory-tracker), which stays the app to use until 1.0 ships.
